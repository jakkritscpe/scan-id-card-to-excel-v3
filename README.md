# Scan Thai ID Card To Excel. 
## Description
This project provides a solution for scanning Thai ID cards and exporting the extracted data to an Excel file. It leverages the `pyscard` library for interfacing with smart card readers, `xlwings` for manipulating Excel files, and `customtkinter` for creating a user-friendly graphical interface.

## Install library list.
```bash
pip install pyscard customtkinter psutil xlwings
```
